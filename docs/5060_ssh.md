# 5060 SSH Notes

Last checked: 2026-07-09.

## Current Public Wi-Fi Route

Use this while the local Windows/WSL machine and the 5060 laptop are on the same
public Wi-Fi:

```bash
ssh dayu@10.1.233.65
```

Verified remote identity:

```text
host: dayu-TX-Gaming-FA608UM-FA608UM
user: dayu
wifi ip: 10.1.233.65/21
repo: /data/projects/WAM
gpu: NVIDIA GeForce RTX 5060 Laptop GPU
```

WSL native `ssh` works for this IP. Windows OpenSSH also works:

```bash
/mnt/c/WINDOWS/System32/OpenSSH/ssh.exe dayu@10.1.233.65
```

## Previous Windows Hotspot Route

Use this only when the 5060 laptop is connected to this Windows machine's local
mobile hotspot:

```bash
ssh dayu@192.168.137.49
```

That address was the old hotspot lease. It timed out when both machines moved to
the public Wi-Fi, so treat it as network-mode-specific rather than permanent.

## Optional Hostname Route

Windows can resolve the mDNS hostname on the public Wi-Fi:

```bash
/mnt/c/WINDOWS/System32/OpenSSH/ssh.exe dayu@dayu-TX-Gaming-FA608UM-FA608UM.local
```

WSL did not resolve the `.local` hostname in the 2026-07-09 check, so prefer the
numeric IP from WSL unless mDNS is configured there.
